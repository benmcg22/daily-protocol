How to run it

  • Warm-up: skip general cardio. Do 2–3 progressively heavier ramp-up sets of the first lift (about 5 minutes). Later exercises need one light set at most. Don't log warm-up sets here.
  • Effort: stop every set 1–2 reps short of failure. The last set of each exercise can go to 0–1 reps in reserve.
  • Progression: when you hit the top of the rep range on every set, add the smallest weight next session and work back up. The green line on each exercise tells you when.
  • Deload: every 6–8 weeks, or when progress stalls across several lifts, cut the sets in half for one week.
  • Supersets: pairs like B1/B2 alternate, with the rest shown on each card between them.
